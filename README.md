# Guess The Number 🎰

A number guessing game written in **C + Raylib**, because apparently I enjoy suffering.

## Features
- Guess a number.
- Computer tells you you're stupid.
- Repeat until you're less stupid.
- 60 FPS of pure disappointment.

## Tech Stack
- **C** — Pain.
- **Raylib** — Pain, but with graphics.
